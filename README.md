# XY 报价助手

工厂家具报价计算器：统一的原材料价格表、款式库和快速改款，按工厂原报价表的公式算出每件产品的成本、运费、利润和 FOB 美金报价。

- 网页：`index.html`（GitHub Pages 发布）
- 数据库连接：`config.js`（Supabase 公开地址和 publishable key）
- 建表和权限：`schema.sql`（在 Supabase SQL Editor 里运行）

价格、款式等业务数据只存在 Supabase 数据库里，需要登录才能读取，不放在这个仓库中。

## 计算方法

1. ① 产品成本 = 小计 × (1 + 管销) + 外配件 × (1 + 损耗) + 不良
   - 小计 = 黑身材料 + 人工 + 表面处理 + 五金 + 包材 × (1 + 预涨) + 纸箱 ÷ 每箱件数
   - 不良 = (黑身材料 + 人工 + 电镀/抛光) × 不良率
2. ② FOB 运费 = 每箱材积(立方英尺) × 运费单价(美金) × 汇率 ÷ 每箱件数
3. ③ 人民币报价 = (① + ②) ÷ (1 − 毛利率)
4. ④ 美金报价 = 人民币报价 ÷ 汇率

管材重量按每米重量公式计算（圆管 (外径−壁厚)×壁厚×0.02466，方管 (边1+边2−壁厚)×壁厚×0.01574，圆棒 直径²×0.00618，板材 宽×厚×0.00787）。
