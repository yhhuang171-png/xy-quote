计算方法
  1. 小计 = 黑身材料 + 人工 + 表面处理 + 五金 + 包材（含预涨）+ 纸箱分摊
  2. 外配件 = 外配件合计 × (1 + 外配件损耗)
  3. 不良 = (黑身材料 + 人工 + 电镀/抛光) × 不良率
  4. ① 产品成本 = 小计 × (1 + 管销) + 外配件 + 不良
  5. ② FOB 运费 = 每箱材积 × 运费单价 × 汇率 ÷ 每箱件数
  6. ③ 人民币报价 = (① + ②) ÷ (1 − 毛利率)；利润 = 报价 − (① + ②)
  7. ④ 美金报价 = 人民币报价 ÷ 汇率
